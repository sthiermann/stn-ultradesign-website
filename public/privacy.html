This website introduces the Ultradesign skill. It does not ask you to create an account or send your application code here.

What the site stores

The website uses your browser's local storage for two display settings:

  • ultradesign-appearance remembers System, Light or Dark.
  • ultradesign-motion remembers whether you switched motion off or on.

These settings remain in this browser and are read by this website. The site's scripts do not send them to a server. You can remove them by clearing this site's data in your browser. If storage is unavailable, the controls still work for the current page.

Loading the website
