01 / THE APPROACH

A clear line from
what you need to what you ship.

Start with the application people actually use. Get recommendations at your pace, keep existing capabilities in view, and trace decisions into the experience.

Explore the complete workflow +
  1. Understand the product. Inspect source and runtime. Discuss tasks, preferences and brand through focused questions with recommendations and tradeoffs. Account for existing capabilities.
  2. Set the direction. Research your selected references and translate them into concrete visual and interaction rules.
  3. Make the work traceable. Local Markdown tickets connect requirements, owners, dependencies and acceptance criteria. Reuse existing project records; no tracker setup is required.
  4. Build the system. Shape shared components and test their open, focused, loading and error states.
  5. Make the concept real. Connect the views and journeys so you can review what people will actually do.
  6. Review and refine. Check what controls promise, what actions change and how loading or failure is explained. Stress-test layouts and drilldowns. Compare each expected outcome with the observed result. Missing or outdated evidence stays open before acceptance.
  7. Implement the agreement. Carry accepted decisions into the frontend and verify the resulting experience.

Ask Codex to install this skill from its GitHub directory:

Install the skill from https://github.com/sthiermann/stn-ultradesign/tree/v0.8.0/skills/stn-ultradesign

If it does not appear, reopen Codex. Manual installation ↗

01 Install the plugin

Enter these two commands, in order, inside Claude Code:

/plugin marketplace add sthiermann/stn-ultradesign
/plugin install stn-ultradesign@stn-ultradesign

Choose your installation scope. Reload plugins if requested. Installation details ↗

02 Open your project. Start a new task.

Use the source code and running application as the starting point. This example requests an audit and a redesign concept:

$stn-ultradesign Audit the entire frontend of this existing application using its current source code and running interface. Ask me about my requirements and design preferences, preserve existing capabilities, and develop a complete interactive design concept. Clarify which earlier design decisions still apply. Independently review and refine the concept with me. Implement production changes only after my approval.

Other tasks, installation help and updates +

Choose your scope. You can request an audit, a concept, design-system work, implementation or a focused fix. See the documented starting prompts ↗

Already installed? Avoid installing a second copy. Update copied skill files or use your client's plugin manager, according to your installation method.

Starting fresh? Open a new task in the application project. Earlier concepts can remain in their existing location; clarify which previous decisions still apply.
